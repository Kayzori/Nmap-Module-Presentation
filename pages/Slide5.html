Nmap Under the Hood

”

Normally, programs connect to other computers using the functions the operating system gives them. Nmap is special because it often builds its own network messages (called packets) from scratch, which gives it more control. This is why some scans need administrator rights (root).

”

Nmap can do multiple different scans to check port's state, TCP scans are so common:

  • TCP SYN Scan
  • TCP connect Scan
  • TCP ACK Scan
  • TCP Window Scan

”

The most common scan is called the SYN scan. Connecting to a service normally takes three steps, called the “handshake”. Nmap does only the first step: it sends a request, sees the reply, and then stops before the connection is fully made. That is fast and leaves fewer traces.
