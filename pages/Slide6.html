Common & Usefull Commands

”

Scans args:

  • -sS (default) for TCP SYN scan
  • -sT (fallback) for TCP Connect scan
  • -sA for TCP ACK scan
  • -sW for TCP Window scan
  • -sU for UDP Scan

”

Host args:

  • -sL list targest to scan
  • -sn disable port scan

”

Port args:

  • -p <range> for range scan
  • --exclude-ports <range> to cancel a range scan
  • -F fast mode, scans top 100 ports
  • -r to scan sequentially
  • --top-ports <number> to scan 'n' most common ports

”

Others args:

  • -O enable OS detection
  • -sV enable service version detection for open ports
  • -T<0-5> set Timing factor (the higher the faster)
  • -iL <nputfilename>: input from list of hosts/networks
