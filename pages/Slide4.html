What is Nmap ?

”

An Nmap scan happens in simple steps. First, you give it a target, like an IP address (for example 192.168.1.1) or a website name. Second, it checks if the target is “alive”, meaning it answers. Third, it checks the ports one by one to see which are open, closed, or protected by a firewall. By default it checks the 1000 most common ports.

”

Here is how a port check works, in everyday terms. Nmap “knocks” on a port. If something answers, the port is open. If the answer is “nobody here”, the port is closed. If there is no answer at all, a firewall is probably blocking it, so the port is filtered. After that, Nmap can go further and try to find out which program and version is running behind each open port, and which operating system the machine uses.
