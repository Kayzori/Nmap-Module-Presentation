Introduction

”

Every device on a network, like a computer, phone or router, uses “ports” to communicate. A port is like a numbered door, and each door is used by a program, such as a website. If a door is open, someone could try to get in.

”

To protect a network, you first need to know which devices are on it and which doors are open. Nmap is a tool that does exactly that. In this presentation we will see what it is, how it works and how to use it.
